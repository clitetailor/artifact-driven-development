# Bootstrap Sequence

Use this as the first-run sequence after copying the scaffold.

## Sequence

1. Read local `AGENTS.md` in the copied docs vault.
2. Read target-project guidance files if present.
3. Inspect repo manifests and major folders.
4. Ask the user only the missing discovery questions.
5. Confirm target repo names and replace placeholders.
6. Update `_registry.md` with real features and modules.
7. Confirm which feature or change to plan first.
8. Select the SDLC track.
9. Select templates.
10. Generate artifacts in dependency order.
11. Validate and present for review.

## First Deliverable

The first useful deliverable should usually be one of:

- a feature doc
- a requirement doc
- a change request

depending on the selected track.
