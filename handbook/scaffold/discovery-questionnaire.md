# Target Project Discovery Questionnaire

Use these questions when the repo does not already provide the answer.

## Product

- What is the product or system called?
- What problem does it solve?
- Who are the primary users?
- What are the main workflows?
- What constraints matter most: speed, accuracy, security, compliance, uptime, cost?

## Scope

- What feature, improvement, or change should be planned now?
- Is this a new capability, an enhancement, or a targeted correction?
- What is explicitly out of scope?

## Repos And Folders

- Is this a monorepo or multi-repo workspace?
- Which folder or repo contains the frontend?
- Which folder or repo contains the backend?
- Which folder or repo contains infra or deployment config?
- Where should the docs vault live?

## Stack

- What frontend framework is used?
- What backend language and framework are used?
- What database or persistence model is used?
- What deployment platform or runtime is used?

## Planning Depth

- Do you want full SDLC planning or only selected artifacts?
- Which artifacts do you want generated now?
- Should wireframes and component specs be included?
- Should API contracts and data models be included?

## Delivery Expectations

- Do tasks need to be decomposed for implementation now?
- Are there deadlines, milestones, or release constraints?
- Are there existing conventions the agent must preserve?
