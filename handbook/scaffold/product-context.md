# Product Context Summary

Use this file as a starting point for product-specific context that informs planning,
design, and implementation decisions.

## Product Snapshot Template

- **Users**: {primary user groups}
- **Core tasks**: {key workflows and outcomes}
- **Environment**: {deployment context, device mix, security/regulatory constraints}
- **Product priorities**: {speed, reliability, collaboration, accuracy, cost, etc.}

## Design Direction Prompt

Answer these questions before finalizing design conventions:

- What type of product experience fits best: dashboard, studio, workflow tool, consumer app, admin console?
- Is the UI primarily dense and operational, or spacious and content-focused?
- Are users keyboard-heavy power users, occasional users, or both?
- Does the product need a dark-first, light-first, or dual-theme design system?

## Example Design Direction: "Professional Studio"

### Core Principles

| Principle | Description |
|-----------|-------------|
| Tool-first | UI feels like a professional instrument, not a marketing page |
| Dense but breathable | High information density with clear visual hierarchy |
| Contextual panels | Resizable, collapsible panels like creative software |
| Keyboard-friendly | Power users can navigate without mouse |
| Warm neutrals | Softer than pure gray, less cold than typical enterprise |

### Reference Products to Study

| Product | What to Borrow |
|---------|----------------|
| Figma | Panel layouts, property inspectors, contextual toolbars, collaborative feel |
| Blender | Workspace customization, dense but organized UI, dark theme done right |
| Linear | Clean typography, subtle animations, refined interactions |
| Notion | Friendly tone, approachable empty states, warm grays |
| Raycast | Command palette, keyboard shortcuts, snappy feedback |
| Retool | Data tables, form builders, configuration panels |
