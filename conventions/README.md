# Conventions

Project-wide conventions and specifications.

## Documents

| Document | Description |
|----------|-------------|
| [Design System](./design-system.md) | Colors, typography, spacing, components — frontend visual standards |
| [Frontend Conventions](./frontend-conventions.md) | Example frontend architecture, routing, state, and API client guidance |

| [Backend API Structure](./backend-api-structure.md) | Example backend folder layout, tech stack, architecture, and implementation patterns |

## Purpose

These documents define cross-cutting conventions that apply to all features:

- **Design System** — Ensures visual consistency across the UI
- **Frontend Conventions** — Provides a reusable frontend baseline that can be adapted to the target stack
- **API Conventions** — Ensures consistent API design and error handling
- **Backend API Structure** — Provides a reusable backend baseline that can be adapted to the target stack
